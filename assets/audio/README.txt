MÚSICA DE FONDO
===============

Para usar el tema de Pokémon orquestado (o cualquier canción) como música
de fondo, coloca AQUÍ un archivo llamado exactamente:

    title.mp3

El sitio lo detecta solo:
- Si el archivo existe  -> suena ese MP3 (en loop, volumen suave).
- Si NO existe          -> suena la melodía chiptune original de respaldo.

Puedes cambiar el nombre/ruta esperada en js/app.js (BGM.fileSrc).
